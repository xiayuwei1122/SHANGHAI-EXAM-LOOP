# 上岸刷题簿（微信小程序）

原生微信小程序开发版，用于市考、事业单位等考试的整卷/模块重复训练、蒙题标记、评分和逐题解析。

首页按“考试类型 + 年份”组合筛选。考试类型集中配置在 `miniprogram/data/exam-types.js`，每套试卷通过稳定的 `examType` 字段归类；后续增加事业单位、社工等类型时，不需要重写首页筛选逻辑。

## 导入题库

```bash
python3 scripts/import_papers.py
```

脚本从公开的考生回忆版页面生成本地题库模块，并下载题目图片。题库并非上海官方发布；当前仅用于所有者自己的开发版。正式公开前需要重新核对内容授权和服务类目。

公开仓库不包含生成后的题目、解析和图片；克隆后先运行上述命令生成本地题库。

## 自检

```bash
npm run check
```

## 微信开发者工具

1. 选择“导入项目”。
2. 项目目录选择本目录。
3. `project.config.json` 已配置当前小程序 AppID；使用其他账号开发时请替换为自己的小程序 AppID 或测试号。
4. 首次编译后，从首页走一遍：整卷/模块 → 标记“蒙的” → 交卷 → 错题/蒙题解析 → 再刷一次。

学习记录保存在微信本地存储，不登录、不上传。
